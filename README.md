# Messi Fan Club Website

Welcome to the **Messi Fan Club** project — a simple, stylish website dedicated to Lionel Messi.  
This site showcases merchandise, special editions, and fan content with a consistent theme and design.

---

## 📂 Project Structure

- `index.html` → Homepage with navigation, intro, merchandise grid, and conclusion.
- `product.html` → Product page with multiple rows of merchandise and special editions.
- `about.html` → About Us page describing the fan club.
- `contact.html` → Contact Us page with form and details.
- `style.css` → Shared stylesheet for consistent fonts, colors, and layout.

---

## 🎨 Features

- Responsive navigation bar
- Merchandise grid with product cards
- Special Editions section with images and descriptions
- Intro section for context and branding
- Consistent theme (black header, white text, clean layout)

---

## 🚀 Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser to view the homepage.
3. Navigate to other pages (`product.html`, `about.html`, `contact.html`) via the menu.
4. Add your own product images by replacing the placeholder `<img>` sources in the HTML.

---

## 🛠 Customization

- Update text in each section to match your fan club’s vibe.
- Replace placeholder images (`golden-jersey.png`, etc.) with your own files.
- Modify `style.css` to adjust colors, fonts, or layout.
